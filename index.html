Про мене

Вітаю! Мене звати Влад, я учень 10-А класу, і я розробник EcoLearn AR Platform - інноваційної платформи для екологічної освіти. Моя мета - створити інтерактивні інструменти для навчання та підвищення екологічної свідомості серед молоді.

EcoLearn AR Platform

EcoLearn AR Platform: інноваційна адаптивна освітня екосистема з гейміфікацією та доповненою реальністю для формування екологічної свідомості молоді

Об'єкт дослідження:

Процес формування екологічної свідомості та екологічної поведінки у молоді в освітньому середовищі.

Предмет дослідження:

Адаптивні методи та технології (AR, machine learning, комп'ютерний зір, гейміфікація) для створення інтерактивної освітньої екосистеми, спрямованої на розвиток екологічної відповідальності.

Проблеми екології, які можна розв'язати у проєкті?

Проєкт EcoLearn AR Platform з модулем колекціонування рослин через ШІ-сканування сприяє збереженню біорізноманіття (ЦСР 15), навчаючи молодь розпізнавати та моніторити локальні види, що допомагає виявляти інвазивні рослини та деградацію екосистем. Гейміфіковані квести мотивують до участі в громадському науковому моніторингу, формуючи дані про здоров'я лісів, степів чи водойм України. Через AR-візуалізацію користувачі бачать вплив вирубки чи забруднення, що підвищує свідомість щодо зміни клімату (ЦСР 13) та сталого споживання (ЦСР 12). Зібрані анонімні дані можуть передаватися екологам для реальних проєктів відновлення.

Цільова аудиторія проєкту

• Підлітки 12–17 років – активні користувачі смартфонів, які люблять ігри та AR, вивчають біологію/екологію в школі та мотивовані гейміфікацією через бали, колекції та лідерборд

• Вчителі, класні керівники – використовують платформу як інтерактивний інструмент на уроках, створюють класові квести та отримують звіти про активність учнів

• Еко-активісти та молодіжні спільноти (15–20 років) – беруть участь у реальних кампаніях моніторингу інвазивних видів, експортують дані у різноманітні проєкти

• Батьки та шкільні адміністрації – підтримують проєкт як позакласну активність.

Використання ШІ: значення в системі (iNaturalist API + Hugging Face модель)

ШІ-модуль Значення в проєкті
iNaturalist API / PlantNet + HF модель Розпізнає рослину з фото → додає в Еко-декс → нараховує бали → показує AR-модель з екологічними фактами. Забезпечує точність 85–95%, регіональну адаптацію (українська флора), анти-чит (GPS + community verify), генерує дані для моніторингу біорізноманіття. Без цього — немає колекціонування, немає гри, немає освіти.
